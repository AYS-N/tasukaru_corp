# デザイン刷新（2026-09-12）

確認済みのデザイン案をルートの静的HTMLへ反映しています。

- 黒いヘッダー・フッターと白い本文背景、Zen Kaku Gothic New / Manrope。
- ロゴは採用されたA案「包み、支える」。
- トップはスクロールに連動した連続する横移動。最後の写真で移動が止まってからコピーを表示します。動きを減らす設定と小さい画面では代替表示になります。
- 6事業の写真は被写体と構図を分け、写真立て・時計の文字盤・通販画面を修正した改訂版を使用しています。サービスの写真には暗くする加工をかけていません。
- 会社情報、住所、電話番号、下層の本文を維持。事業一覧のバナーのみ、確認済みの「整理から買取・再販売まで、一貫して対応」に変更しています。
- ヘッダーとスマートフォンのメニューに「トップ」を追加しています。
- スマートフォンの最初・最後の写真上のコピーは、細めの見出し、2行目の字下げ、意味の区切りでの改行と広めの左右余白で調整しています。幅320px・390pxと高さ440pxの表示、最後のコピーの出現を確認しました。PCの文字組みは維持しています。
- トップの横移動中はヘッダーを隠して写真を画面いっぱいに表示。最後の場面を終えて縦スクロールに移るとヘッダーが現れ、戻ると隠れます。動きを減らす設定・高さ440px未満の画面・下層ページでは通常のヘッダーを表示します。

## 編集対象

配信するファイルはリポジトリのルートにあります。共通の変更は `design.css`、`refinement.css`、`common.js`、トップの横移動は `hero-scroll.css` / `hero-scroll.js` にあります。`project/` は以前の書き出しデータです。

新しい写真とロゴは組み込み画像生成で作成したイメージです。実在の社員・施工実績を示す写真ではなく、画像内の通販画面も架空の商品一覧です。

## 公開用の調整と確認

確認用の表示、検索除外タグ（404を除く）、フォームの疑似確認処理を除いています。既存の `contact-send.php` へのPOST、項目名、種別切替、成功・エラー表示を維持しています。PHP・SMTPの設定手順は `mail-setup.md` を参照してください。メールの実送信は今回の表示検証では行っていません。

16ページの内部ファイル参照、会社情報・下層本文、JavaScriptの構文を検証。ブラウザーでトップの表示・横移動、ナビゲーション、フォームの項目切替、スマートフォンのメニューを確認しています。

Googleマップの埋め込み設定と座標は元のままです。アプリ内ブラウザーで地図が空白になる現象は元の公開サイトでも確認されており、通常ブラウザーでの確認が残っています。元から存在する仮メールアドレス等の未確定情報も変更していません。
